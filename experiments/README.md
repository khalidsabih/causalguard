# Experiment outputs

Files in this directory are smoke-test outputs unless explicitly generated as part of the final study.

Do **not** treat `latest/`, `policy_benchmark.csv`, or `matrix_summary.csv` as research conclusions. Their purpose is to verify that the end-to-end system behaves coherently and exposes expected failure modes.

Before publication, the large experiment matrix should be pre-specified in `reports/paper/research_protocol.md`, repeated across many seeds, and summarized with uncertainty intervals and sensitivity analyses.
